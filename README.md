# [cite_start]🚀 API de Gerenciamento de Pedidos - Teste Técnico Jitterbit [cite: 20, 21, 224]

[cite_start]Esta é uma API RESTful desenvolvida em Node.js com Express para o teste técnico da equipe de Professional Services da Jitterbit[cite: 2, 3, 223]. [cite_start]O objetivo principal da aplicação é gerenciar pedidos, permitindo operações de CRUD (Criar, Ler, Atualizar e Deletar)[cite: 224, 225]. 

[cite_start]Um dos principais requisitos atendidos foi a transformação (mapping) dos dados: a API recebe um payload complexo e o mapeia para um formato padronizado antes de salvar no banco de dados.

## 🛠️ Tecnologias Utilizadas
* [cite_start]**Node.js** [cite: 223]
* **Express** (Framework web)
* **Banco de Dados em Memória** (Simulando persistência de dados estruturada para o teste)

## 📦 Como rodar o projeto localmente

1. Clone este repositório para a sua máquina.
2. Acesse a pasta do projeto no terminal.
3. Instale as dependências executando o comando:
   ```bash
   npm install
   node index.js

   A API estará rodando e pronta para receber requisições em http://localhost:3000
